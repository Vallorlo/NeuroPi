About the EEG Processor

This tool processes raw EEG data files by analyzing audio recordings or timestamp files to identify speech events. It then marks these events in the EEG data and creates a labeled dataset for analysis and machine learning.

New! The processor now creates a word_label column that contains the spoken word during speech events and "sil" (silence) during non-speech periods, making the data more suitable for machine learning tasks.

About Speech Detection

For stages with speech (1 and 4), audio files are analyzed to detect speech segments. For non-speech stages (2, 3, and 5), timestamp files are used to mark events. The processor will now create a word_label column in the data where each row is labeled with either the word (during speech) or "sil" (during silence).

New Word Labeling Approach

The processor now creates a word_label column that contains:

  • The actual word (e.g., "hello") during speech events
  • The label "sil" (silence) during non-speech periods

This format makes the data more suitable for machine learning tasks by providing explicit word labels for every time point.

Note: The traditional binary event columns (e.g., hello_event) are still created for backward compatibility.

Time word_label hello_event
0.125 sil False
0.250 hello True
0.375 sil False
