About Motor Imagery Classification

Motor imagery classification uses EEG signals to detect imagined movements without actual physical execution. This BCI system can classify four different mental states:

Supported Classes
  • 0Right Hand Movement
  • 1Left Hand Movement
  • 2Feet Movement
  • 3Rest State
Technical Details
  • Architecture: ATCNet with attention
  • Channels: 14 EEG electrodes
  • Sampling Rate: 128 Hz
  • Window Size: 2 seconds
Quick Start
1. Upload EEG Data 2. Train Model 3. Start Prediction
Tip: Upload multiple sessions for better model performance.

Electrode Regions
  • Frontal (F3, F4, F7, F8, AF3, AF4)
  • Frontal-Central (FC5, FC6)
  • Temporal (T7, T8)
  • Parietal (P7, P8)
  • Occipital (O1, O2)
Motor Imagery Relevance
  • C3/C4 region: Primary motor cortex activity
  • Sensorimotor rhythms: 8-30 Hz frequency bands
  • Event-related desynchronization: Key feature for classification
  • Spatial filtering: Common spatial patterns (CSP)
