  • Word Column: Contains the target words (green, purple, yellow, red, blue) or "XXXXX" for rest

P300 Data Format Requirements
Required CSV Structure

Your P300 visual trial data should be in CSV format with the following columns:

Column Name Description Example Values
Timestamp Time information 0.0078125, 0.015625, ...
F3, FC5, AF3, F7, T7, P7, O1, O2, P8, T8, F8, AF4, FC6, F4 EEG channel data (μV) -12.5, 8.3, -15.2, ...
word Target word or rest period green, purple, yellow, red, blue, XXXXX
Target Words

The system supports the following target words:

green purple yellow red blue XXXXX (rest/silence)
Technical Specifications
  • Sampling Rate: 128 Hz (recommended)
  • Channels: 14 EEG channels from EPOC+ device
  • Data Type: Continuous EEG recording during visual word presentation
  • File Format: CSV with headers
  • Encoding: UTF-8
Tip: Ensure your visual trial data contains sufficient examples of each target word for effective P300 model training. A balanced dataset with equal representation of all words will yield the best results.
