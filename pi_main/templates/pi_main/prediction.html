EEG Prediction Instructions
How to use the EEG Prediction tool:
  1. Select a trained model from the dropdown
  2. Connect your EEG headset by clicking the "Connect EEG Headset" button
  3. Choose a participant (optional)
  4. Set the recording duration (5-10 seconds recommended)
  5. Enter a target word if you're testing specific words
  6. Enable enhanced detection options (recommended)
  7. Click "Record & Predict"
  8. Think about or speak the word during the recording period
  9. View results when collection is complete
About Enhanced Speech Detection

The enhanced speech detection features help the model better distinguish between actual speech and silence in EEG signals:

  • Custom Decision Thresholds - Uses different confidence thresholds for silence vs. speech classes, making the model less likely to default to silence
  • Majority Voting - Combines predictions from multiple time windows to improve stability and accuracy

These features are enabled by default and recommended for most users.

Tips for best results:
  • Ensure the EEG headset is positioned correctly and has good contact
  • Try to minimize movement and muscle tension
  • Focus clearly on the word you're thinking about
  • For vocal tests, speak clearly but naturally
  • Try multiple attempts to improve accuracy
Troubleshooting:
  • If the EEG status indicator remains red, try reconnecting or reseating the headset
  • If predictions seem random, try increasing the sample duration
  • Different models may perform better with different participants
  • If you consistently get "silence" predictions, try a model trained with enhanced speech detection
