Live Prediction Instructions
How to use the Live Prediction tool:
  1. Select a trained model from the dropdown
  2. Connect your EEG headset by clicking the "Connect EEG Headset" button
  3. Choose a participant (optional)
  4. Set the sample duration (default: 5 seconds)
  5. Enter a target word if you're testing specific words
  6. Click "Start Prediction"
  7. Think about or speak the word during the recording period
  8. View results when collection is complete
Tips for best results:
  • Ensure the EEG headset is positioned correctly and has good contact
  • Try to minimize movement and muscle tension
  • Focus clearly on the word you're thinking about
  • For vocal tests, speak clearly but naturally
  • Try multiple attempts to improve accuracy
  • PyTorch CNN-LSTM models typically provide better results than TensorFlow models
  • Enable advanced preprocessing for better artifact removal
Troubleshooting:
  • If the EEG status indicator remains red, try reconnecting or reseating the headset
  • If predictions seem random, try increasing the sample duration
  • Different models may perform better with different participants
  • If using a PyTorch model, check if speech is being detected correctly
