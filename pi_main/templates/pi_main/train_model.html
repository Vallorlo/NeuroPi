About PyTorch CNN-LSTM Architecture
Two-Stage Model Pipeline

This architecture uses two specialized neural networks:

  1. Speech Detection Network: Determines if speech is present in the EEG data
  2. Word Classification Network: Identifies the specific word being thought or spoken

This approach improves accuracy by tailoring each model to its specific task.

Advanced Features
  • CNN Layers: Extract spatial features from EEG signals
  • LSTM Networks: Capture temporal relationships in the data
  • Attention Mechanism: Focuses on the most relevant parts of the signal
  • MNE Preprocessing: Advanced artifact removal (optional)
Recommended: This architecture typically achieves 15-30% higher accuracy than the legacy TensorFlow RNN model.
About TensorFlow RNN Architecture (Legacy)

This is the legacy architecture that uses a single GRU-based recurrent neural network for word classification.

Note: This architecture is provided for backward compatibility. The newer PyTorch CNN-LSTM architecture typically provides better results.
